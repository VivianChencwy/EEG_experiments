================================================================================
                              KEY INSIGHTS
================================================================================

1. WEIGHT EVOLUTION IS CRITICAL FOR SMALL DATASET
   • Fixed weights (Ablation 2) = WORST P3 performance (-3.75%)
   • Adaptive evolution allows gradual emphasis on small dataset
   • Avoids early overfitting while ensuring sufficient learning

2. SPLIT-BN ACTUALLY HURTS SMALL DATASET
   • Unified BN (Ablation 4) = BEST P3 performance (+1.56% vs TF-DWT baseline)
   • Small dataset has unstable statistics with separate BN
   • Unified BN provides more robust statistics from combined data

3. MMD ALIGNMENT IS IMPORTANT BUT NOT SUFFICIENT ALONE
   • Without MMD (Ablation 3): P3 2nd best, but overall WORST
   • MMD helps alignment but needs proper weighting for both datasets
   • Keeps AVO performance from degrading

4. EQUAL WEIGHTS UNDERPERFORM ON SMALL DATASET
   • Equal weights allow large dataset to dominate gradient updates
   • Small dataset needs emphasis to avoid being "washed out"

================================================================================
                        RECOMMENDED CONFIGURATION
================================================================================

For Few-Shot / Small Dataset Learning:

✅ KEEP:
   • Domain-specific weight evolution with warmup (CRITICAL)
   • MMD alignment for domain distribution matching (IMPORTANT)
   • Early stopping on target (small) dataset validation

❌ REMOVE:
   • Split-BN → Use unified BN instead (BENEFICIAL)

🎯 BEST CONFIGURATION: Ablation 4
   • P3: 0.5931 (best for small dataset)
   • Overall: 0.6442 (best overall)
