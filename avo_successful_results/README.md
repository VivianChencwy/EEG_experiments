## 方法
- **基础方法**: TF-DWT (Target-Focused Domain Weighted Training)
- **改进**: Prototype Networks + Mixup + BN共享 (165244实验)
- **核心参数**:
  - Domain weight: ~8-17x (根据样本比例)
  - MMD weight: 0.4-0.68
  - Focal loss: gamma=2.0-3.6, alpha=0.5-0.65
  - Batch size: 32
  - Learning rate: 0.003
  - Max epochs: 1000
  - Patience: 150
